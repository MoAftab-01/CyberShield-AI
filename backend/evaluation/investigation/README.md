All scenario text is original synthetic CC0-1.0 material. Real CVE identifiers provide realistic routing cases; fixture prose is not official intelligence or guidance.

cases.json contains expected outcomes and source-level relevance judgments. scenarios.py generates source-only fixtures without reading labels. Runtime demo adapters import neither evaluation file.

Evaluation runs the actual compiled graph and canonical quotation verifier. Source coverage is expected source families represented by accepted quotations, not answer completeness or factual accuracy. No models, network, shared indexes or application databases are used.
